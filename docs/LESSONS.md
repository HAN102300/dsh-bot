# LESSONS — 从事故蒸馏的工程原则

> 这份文档是 [docs/archive/](./archive/) 里全部事故复盘的蒸馏。
> 原文保留了完整现场；这里只留可复用的原则。
> 每一条都来自真实的故障，不是从别处抄的最佳实践。

## 一、失败必须可见

**1. 一个失败不能放大成全部失败。**
一个 `try/catch` 包住一串工具注册，一个未定义变量（`nowIso`）让 14 个工具静默消失，页面照常渲染。
→ 每个注册块独立 catch + 注册后断言数量（现在有 plugin-load.test.ts）。

**2. 成功必须意味着真的做了事。**
空输出 + 0 token + 0 成本曾被标记为 `success`——看起来跑通了，其实模型一次都没被调用。
→ 空输出 = failed（EMPTY_OUTPUT）；演习有拦截 = partial，不是 success。

**3. `try/catch` + 降级返回值 = 错误隐身。**
降级本身没错，错在降级后没有把「我降级了」暴露到显眼处（`os is not defined` 静默降级到错误 provider）。
→ 降级必须带 `degraded` 标记，且降级结果不覆盖配置默认值。

**4. 0 和「不知道」必须长得不一样。**
`¥0.0000` 同时表示「真免费」和「算不出来」——误导性 UI。
→ 成本三态（exact/free/unknown），展示层禁止裸 `toFixed`（未知时那是 undefined，会直接抛错）。

**5. 静默丢弃比迟到更糟。**
错峰推迟的任务曾只记一个时间戳就丢掉——推迟时刻不匹配 cron，任务永久蒸发，界面还显示「已错峰」。
→ 承诺的执行必须有持久化队列；迟到也执行。

**6. 失败时用户看得见吗？**
这是验收每个功能时多问的一句：算不出成本显示「未知」，模型不存在在配置时就拒绝，没节奏用警告色说「它不会自己跑」。

## 二、承诺与实现之间不能有缝

**7. 承诺的能力必须有真实执行路径。**
用户写下「每过 4 小时」，调度器却从不看目标——目标只是一句愿望。产品承诺的能力在代码里没有路径时，用户会先相信它，然后在最需要的时候失望。
→ 写下的每一句自然语言，不去解析就等于没写。

**8. 执行入口必须唯一。**
预算检查曾只设在两个工具入口，调度器与面板路径绕过——同一个承诺三条路径两种兑现。
→ 预算门收口在 RoutineRunner（所有路径共用的唯一入口）。

**9. 撤销本身必须可撤销。**
回滚曾直接覆盖工作区、事先不打快照——回滚选错，回滚前的状态永久丢失。一个卖「收得回」的产品，自己的回滚收不回。
→ restore 前自动快照；归档引用的快照豁免滚动清理。

**10. 能力不存在就不给开关。**
设置页曾有五组「存了没人读」的死配置——用户配置不存在功能，是被辜负的信任。
→ 删掉；功能落地时再出现。

## 三、文档与注释

**11. 文档不许手抄代码。**
README 18 个工具、API.md 15 个、manifest 21 个、实际 22 个——四个数字四个出处。
→ 清单从代码自动生成（`node dev/gen-tools-doc.mjs`），手抄必过期，过期即错。

**12. 注释不许许诺代码没有的东西。**
快照模块头注释宣称「内容寻址 / 增量」，实现从来是全量复制。
→ 注释描述现状，不描述愿望。

**13. 块注释里不能出现 `*/` 序列。**
`bot_*/routine_*` 写进注释，`*/` 提前闭合了注释块，整个文件语法错误。
→ 注释里的通配符写法要用空格隔开（`bot_ 与 routine_ 前缀`）。

## 四、验证文化

**14. 编译期防线是最便宜的防线。**
`tsc` 曾报 123 个错误、被「过滤着看」——`nowIso`/`os`/`expandHome` 三次同类事故全在这 123 个里面。
→ 阶段 0 修到 0 错，`verify:all` 前置 typecheck。词法检查脚本（check-undefined.mjs）是没修好 tsc 前的绷带。

**15. 任何防线要证明能抓到问题。**
一个永远通过的检查等于没有检查。check-undefined 曾故意删掉 import 验证能抓到。
→ 测试覆盖时间换算却没覆盖 tick+shift 组合路径——三个 P0 全在测试盲区。新防线上线前先证明它能红。

**16. 测试钉死环境，不许依赖运行时刻。**
调度测试曾在高峰时段全挂（错峰把触发挪走了）。
→ 测试里显式关掉错峰 / 用固定日期。

## 五、协作与流程

**19. 测试 fake 的形状 ≠ 宿主真身的形状。**
工具循环单测里 fake 的 `tools.list()` 返回 `{name}` 对象数组，测试全绿；
真机上宿主返回的形状对不上（且原生 tools 选项被适配器静默丢弃），
模型自述「没有可用工具」，Bot 每 4 小时空转烧钱。用户建了又删——
这是「看起来一切正常」的另一种形态：不是静默失败，是**静默没挂载**。
→ 凡是从宿主/外部拿的东西，落盘诊断它的真实形状
  （`diag.hostTools = { count, probeMethod, sample }`）；
  归一化做在消费端，不信任生产端；
  协议选不依赖中间层能力的（文本协议），原生能力只做增强。



**17. 做快照回滚产品的仓库，自己必须有快照。**
1 万行代码曾零版本控制。`git init` 是全项目性价比最高的一个修复。

**18. 每个阶段独立成提交。**
回滚基线比回滚机制更早可用。
